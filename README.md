# 📘 VU CSE Midterm Routine

**A modern, premium Progressive Web App for displaying and managing the Midterm Examination Routine**

## ✨ Features

### 📊 Smart Dashboard
- **Live Next Exam card** with dynamic status detection
- **Real-time countdown** (days / hours / minutes / seconds) updating every second
- **Live stats** — total, upcoming, completed, next exam
- **Auto-updating progress bar** showing examination completion

### 🎯 Exam Management
- **Beautiful exam cards** with course code, title, date, time, and status
- **Automatic status calculation** — Upcoming / Tomorrow / Today / Ongoing / Completed
- **Vertical timeline** view of the entire schedule
- **Monthly calendar** with highlighted exam dates — click any date for details
- **Exam detail modal** with full information

### 🔍 Search & Filter
- **Global instant search** by course code, title, date, or day
- **Highlighted matches** in search results
- **No page reload** — everything updates live

### 📚 Study Preparation (Optional)
- **Preparation percentage tracker** for each subject (−25% / +10% / +25% / Mark Prepared)
- **Study notes** — auto-saved per subject
- **Topic checklist** — add, check, and remove topics to study

### 🔔 Smart Reminders
- **Six preset reminders** — 7 days, 3 days, 1 day, 12 hours, 1 hour, 30 minutes before exam
- **Browser notifications** when reminders fire
- **Manageable from Settings** panel

### 🎨 Themes
- **Light Mode** ☀️
- **Dark Mode** 🌙
- **System Mode** 💻 (follows OS preference)
- **Persisted in localStorage**

### 📱 Mobile-First Design
- **Responsive on every device** — Android, iPhone, tablet, laptop, desktop
- **Bottom navigation** on mobile, sidebar on desktop
- **Touch-friendly controls** and large tap targets
- **Sticky header** with instant global search

### 🚀 PWA (Progressive Web App)
- **Installable** on Android, iOS, and Desktop like a native app
- **Offline support** via service worker
- **App manifest** with proper icons and theme color
- **Cache-first strategy** for instant loading
